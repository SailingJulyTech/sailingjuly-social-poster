SailingJuly Social Auto-Poster — Privacy Policy

Last updated: 2026-08-25

This page describes the data practices of the SailingJuly Social Auto-Poster, a personal automation tool that publishes pre-produced video content to the SailingJuly Facebook Page, Instagram account, and TikTok account on a schedule, on behalf of the SailingJuly creator (its owner and sole operator).

What this tool is

It is a small, single-user script (not a public app, service, or product offered to other users) that connects to each platform's official API to post already-finished SailingJuly video content at scheduled times. It has no public sign-up, no other users, and no audience-facing component.

What data it accesses

Via TikTok's Content Posting API, the tool requests the video.publish and video.upload scopes, and reads basic creator profile info (username, nickname, avatar, and allowed privacy/posting options) for the single connected SailingJuly TikTok account, solely to confirm which account a post is about to go to before publishing it.

It does not access, collect, or process data belonging to any TikTok viewer, follower, or other third party — only the connected creator account's own posting permissions.

What it does with that data

The creator profile info is used only to display the target account before a post is published and to select a valid privacy level for that post. The OAuth tokens are used only to call TikTok's official posting endpoints for content the SailingJuly creator has already produced and queued.

Storage and retention

API credentials (client key/secret, refresh token) are stored as encrypted secrets in a private GitHub Actions configuration, accessible only to the repository owner. They are not logged, not shared with any third party, and not used for advertising, analytics, or any purpose other than posting the SailingJuly creator's own content to their own connected accounts.

Revoking access

The connected TikTok account owner can revoke this app's access at any time from TikTok's app settings (Settings and privacy → Security → Manage apps), which immediately invalidates the stored token.

Contact

Questions about this tool or its data practices can be sent via the SailingJuly YouTube channel (youtube.com/@sailingjuly).
